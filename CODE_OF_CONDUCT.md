# Código de conducta

Este proyecto adopta los principios del [Contributor Covenant 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

**Nuestro compromiso:** que participar sea una experiencia libre de acoso para todas las personas, sin importar edad, cuerpo, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, nacionalidad, apariencia, religión u orientación.

**Esperamos:** respeto, críticas constructivas centradas en el código y no en la persona, y paciencia con quien está aprendiendo.

**No se acepta:** insultos, acoso, lenguaje o imágenes sexualizados, publicar datos privados de otras personas, ni cualquier conducta que razonablemente se considere inapropiada.

**Aplicación:** el mantenedor puede editar o eliminar comentarios, issues y PR que incumplan este código, y bloquear temporal o permanentemente a quien lo haga. Para reportar una conducta, escribe un mensaje privado al mantenedor a través de GitHub.
